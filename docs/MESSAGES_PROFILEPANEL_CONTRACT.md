# Messages ProfilePanel Contract

Одна canonical ProfilePanel используется для MAX, Telegram, WhatsApp, звонка,
provider-only Contact, Contact без номера, без профилей, с одним профилем и с
несколькими парками.

Панель всегда содержит header, источник, число уникальных каналов, состояние
профилей, главный профиль, предложения, прикреплённые профили, номера и
каналы, Telegram-бот, поля, tags, задачи и свёрнутые technical data.

Главный профиль остаётся видимым. Полный список группируется по паркам,
активные профили показываются выше исторических, исторические свёрнуты.
Два работающих профиля одного парка являются заметной anomaly, а не поводом
для случайного выбора. Локальное сворачивание списка сохраняется при
background refresh и не меняет Contact data.

Строка канала всегда едина: status dot, иконка, название, короткие badges,
spacer, «Написать». Действие не переносится на вторую строку. Вторичный badge
при нехватке места скрывается с tooltip, а не вытесняет действие.
