# Messages Search Contract

## Приоритет результата

Поиск нормализует телефон и ранжирует canonical Contact выше provider-only
карточки. Поддерживаются полный и форматированный телефон, ФИО/префикс,
Telegram username и внешний ID DriverProfile.

## Безопасность

Одинаковое имя показывает все релевантные результаты и не связывает их.
Номер с несколькими владельцами считается ambiguous: поиск может показать
карточки для проверки, но не выбирает одну для автоматической привязки.
Merged или archived Contact не должен вытеснять canonical Contact.

## Профили в парках

Поиск DriverProfile идёт по локальному каталогу всех шести парков. Результат
показывает парк и доступные данные профиля. Прямой URL в диспетчерскую не
генерируется, пока его контракт для конкретного парка не доказан: вместо
догадки оператор получает идентификатор и телефон для безопасной ручной
проверки.
