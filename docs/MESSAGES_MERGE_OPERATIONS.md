# Messages Merge Operations

## Когда использовать

Merge применяется только когда оператор доказал, что две карточки - один
человек. Совпадающее имя не является доказательством.

## До подтверждения

1. Откройте обе карточки и проверьте номера, каналы и профили.
2. Убедитесь, что номер не имеет нескольких canonical владельцев.
3. Посмотрите preview: сообщения, вложения, звонки, задачи и tags должны
   остаться доступны после redirect.
4. Проверьте, что выбранная основная карточка действительно canonical.

## Выполнение и откат

Исполнитель сначала строит plan, затем выполняет транзакционную операцию и
сохраняет audit/rollback manifest. В случае stale version, циклического
redirect или конфликта identity операция останавливается без частичной
перезаписи. После merge старая карточка не становится независимым дублем, а
перенаправляет к canonical Contact.

## Запрещено

Нельзя объединять карточки только из-за одинакового ФИО, выбирать случайный
профиль или удалять историю для устранения конфликта.
