# Contact Resolution Acceptance

## Контакты для контрольного сценария

- Ремезов: поиск `9222155`, шесть парков, главный профиль YOKO.
- Шабуров: поиск `шабу`, один профиль, главный профиль Наш Автопарк.

Используйте только проверочные действия, не отправляйте реальные сообщения
водителям ради приёмки.

## Проверки

1. Поиск по ФИО и по нормализованному телефону открывает одну canonical
   карточку; provider-only дубли не подменяют её заголовок.
2. Панель справа показывает сохранённые профили, главный профиль и каналы без
   фиктивных «Парк: Яндекс» и «Роль: Водитель».
3. У Ремезова видны шесть парков, главный YOKO, история свёрнута.
4. У Шабурова виден один профиль Наш Автопарк.
5. Добавление номера показывает корректные FREE, SAME, OTHER и AMBIGUOUS до
   подтверждения и не создаёт дубль.
6. Профиль другого Contact нельзя перенести без явного подтверждения.
7. При ошибке обновления Яндекса виден человекочитаемый warning и последняя
   сохранённая информация; raw JSON, `429`, `dismissed` и park code скрыты.
8. Строки MAX, Telegram и WhatsApp остаются однострочными, а «Написать»
   выровнена справа.
9. Telegram-бот показывает понятное состояние привязки к выбранному профилю.
10. Свернутые technical data содержат версию ответа и build marker; основная
    панель их не показывает.
