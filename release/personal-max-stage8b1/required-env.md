# Required environment names

No values are part of this package. All feature allowlists default to empty/false and must contain one exact approved account during Stage 8B2.

Gateway: `MAX_RAW_JOURNAL_ENABLED`, `MAX_INBOUND_NORMALIZER_ENABLED`, `MAX_SHADOW_COMPARISON_ENABLED`, `MAX_PERSONAL_LIVE_CAPTURE_ENABLED`, `MAX_PERSONAL_GATEWAY_DATABASE_URL`, `MAX_PERSONAL_CAPTURE_HMAC_KEYS_JSON`, `MAX_PERSONAL_GATEWAY_BIND_HOST`, `MAX_PERSONAL_GATEWAY_PORT`, `MAX_PERSONAL_GATEWAY_PRIVATE_NETWORK`, `MAX_PERSONAL_GATEWAY_REQUIRED_MIGRATION`, `MAX_PERSONAL_BROWSER_OWNERS_EXPECTED`, `MAX_PERSONAL_CAPTURE_REQUEST_MAX_BYTES`, `MAX_PERSONAL_CAPTURE_BODY_TIMEOUT_MS`, `MAX_PERSONAL_CAPTURE_HEADER_TIMEOUT_MS`, `MAX_PERSONAL_CAPTURE_AUTH_CLOCK_SKEW_MS`, `MAX_PERSONAL_GATEWAY_WORKER_BATCH_SIZE`, `MAX_PERSONAL_GATEWAY_WORKER_POLL_MS`, `MAX_PERSONAL_CAPTURE_RECENT_ACK_MS`, `MAX_PERSONAL_NORMALIZER_LAG_LIMIT_MS`, `MAX_PERSONAL_COMPARISON_LAG_LIMIT_MS`.

Producer: `MAX_PERSONAL_ACCOUNT_ID`, `MAX_PERSONAL_LIVE_CAPTURE_ENABLED`, `MAX_PERSONAL_CAPTURE_SPOOL_PATH`, `MAX_PERSONAL_CAPTURE_SPOOL_MAX_BYTES`, `MAX_PERSONAL_CAPTURE_SPOOL_WARNING_RATIO`, `MAX_PERSONAL_CAPTURE_SPOOL_CRITICAL_RATIO`, `MAX_PERSONAL_CAPTURE_INGRESS_URL`, `MAX_PERSONAL_CAPTURE_HMAC_KEY_ID`, `MAX_PERSONAL_CAPTURE_HMAC_SECRET`, `MAX_PERSONAL_CAPTURE_DRAIN_INTERVAL_MS`, `MAX_PERSONAL_CAPTURE_REQUEST_TIMEOUT_MS`, `MAX_PERSONAL_CAPTURE_DRAIN_BATCH_SIZE`.

Release selection: `MAX_PERSONAL_GATEWAY_STAGE8B1_IMAGE`, `MAX_WEB_SCRAPER_STAGE8B1_IMAGE` must be immutable exact references. `latest`, `stable` and `production` are prohibited.

Rotation order: provision a new gateway key ID alongside the current one, roll the producer to the new key ID, verify authenticated ACKs, then remove the old gateway key. Secret values must never enter Compose, Git, logs or metrics.
