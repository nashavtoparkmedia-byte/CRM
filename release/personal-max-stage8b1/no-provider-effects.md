# No-provider-effects statement

The gateway is browserless and imports no sender, outbound actor, dispatch authority, Route Registry mutation, CRM projection, Puppeteer or Playwright module. It has no MAX URL or provider credential configuration.

Capture remains observation-only. Enabling capture does not enable a sender. Enabling normalization does not enable CRM projection. Enabling comparison does not perform provider effects. Stage 8B1 launched no browser, opened no MAX session and performed no provider action.
