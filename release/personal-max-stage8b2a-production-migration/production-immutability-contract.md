# Production immutability contract

The authorized future mutation is limited to the exact eight additive database migrations and fresh backup files. Docker project container identity/state/restart hashes and `/opt/crm` HEAD/status must remain unchanged. The canonical production status binding is SHA-256 of the raw byte stream from `git status --porcelain=v2 --untracked-files=all`; sorting that stream would change the accepted hash and is forbidden. The deterministic disposable migration and Prisma-diff runners have no public port, carry exact ownership labels, refuse pre-existing name collisions, and are removed by `--rm` plus bounded label-verified failure cleanup. The action does not deploy, restart, alter the scraper, mount the MAX profile, enable capture, start a gateway service, or perform destructive database rollback.
