# Partial failure contract

Any nonzero migration runner exit stops the action. Before the sanitized incident report is rendered, bounded cleanup targets only the two deterministic Stage 8B2A runner names and refuses removal if their exact Stage/role labels do not match. The report records each runner cleanup state, whether cleanup completed, the validated fresh backup SHA/bytes/object count/config SHA/status, and observed Personal MAX ledger names. Deploy remains blocked and the fresh backup is preserved. The operator must not drop tables, delete or edit `_prisma_migrations`, use `migrate resolve`, or attempt a destructive rollback.
