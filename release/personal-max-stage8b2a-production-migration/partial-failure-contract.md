# Partial failure contract

Any nonzero migration runner exit stops the action. PostgreSQL discovery failures retain exact non-secret classifications for missing, multiple, stopped, image-mismatched, network-mismatched, alias-missing, credential-binding, or identity-change conditions. Before the sanitized incident report is rendered, bounded cleanup targets only the two deterministic Stage 8B2A runner names and refuses removal if their exact Stage/role labels do not match. A separate bounded cleanup removes the credential workspace only when it is a non-symlink directory matching the exact temporary-name pattern and `root:root:0700` metadata.

The report records each runner cleanup state, whether cleanup completed, the validated fresh backup SHA/bytes/object count/config SHA/status, and observed Personal MAX ledger names. It never records inspect contents, environment values, raw commands, SQL, stderr, or credentials. Deploy remains blocked and the fresh backup is preserved. The operator must not drop tables, delete or edit `_prisma_migrations`, use `migrate resolve`, or attempt a destructive rollback.
